# 开发任务

## 阶段一：本机基础原型
- 检查环境并确定技术栈；记录依赖与启动方式。
- 创建网页及后台健康检查。
- 占位角色、角色选择、三种背景、文本输入、倾听/说话状态。
- 区分演示模式与真实服务，提供错误提示。
- 验证启动、角色和背景切换、移动屏幕布局。

## 阶段二：口播闭环
- 接入可替换 TTS 服务；稿件分段、停顿、读音修正。
- 声音与动画时间轴、字幕、视频合成与下载。
- 验证实际导出文件的画面、声音和时长。

## 阶段三：实时互动
- 语音输入、对话服务、流式播放与打断。
- 接入现成二维角色，验证能力映射与资源许可。

## 阶段四：多角色与 UE
- 第二种三维角色、UE 协议适配、真实工程联调。
- MetaHuman 作为可选角色，动物与机器人分别适配。
- 换装、布料分档、舞台走位和多用户会话。

## 阶段五：产品化
- 手机实机验证、账户与任务存储、成本观测。
- 高质量渲染、直播扩展及 Steam 接入分别规划。

## 并行：幽默能力
- 结合 robot-reference-review.md 建立记忆、上下文接话与现场互动评测；区分观察证据和待实现目标。
- 确认素材与账号，整理机制及样本。
- 建立未参与训练的新情境评测、重复率与接话效果评测。
- 比较提示词、机制检索和微调；接入统一模型接口。

## 服务接待工作线（新增，分阶段实现）
- 基础：人员目录、场所/企业隔离、角色权限、偏好与记忆管理页面；使用模拟摄像头事件和通知验证流程。
- 视觉：接入一款实际摄像头，检测、追踪、自愿登记、身份确认、陌生/不确定状态；多人与遮挡处理。
- 企业：员工目录、预约/来访登记、口信、快递通知、员工确认与接待状态。
- 餐厅：昵称、熟客档案、口味/配料偏好、确认后更新、再次到访问候。
- 集成：飞书/钉钉适配，失败重试、幂等与状态回执；实际通知需配置账号和明确启用。
- 门禁：先模拟，再验证权限规则与独立身份校验；实际设备联调须明确授权，不由大模型直接批准开门。
- 验收：误识别不泄露档案、不打开门；拒绝登记可继续服务；档案可查看纠正删除；跨企业档案不可互查；重复事件不重复发消息。
