# 声音开发与使用

## 已接入
设置页提供本机声音库、性格（活泼/沉稳/温柔/讲述）、状态（自然/愉快/情感饱满/忧伤）、强度与基础语速。浏览器声音只做近似语速/音高；简单表情和动作跟随状态，不是音素嘴型或专业情感演绎。
选择声音后可试听、朗读稿件，或启用自动朗读回答。声音配置按场所与角色保存在当前浏览器，角色回答内容仍来自模拟对话。
样音可上传或主动录制，授权后保存到项目 data/voice-samples，按场所隔离并可原音试听、删除；未配置模型时生成返回明确错误。麦克风实机和扬声器需进一步验收。

## 本地模型准备
独立 .venv-tts 环境，CPU Torch，与现有网页分离。services/tts/qwen_server.py 使用 Qwen3-TTS-12Hz-0.6B-Base、float32/eager，绑定127.0.0.1:9880，模型加载后离线推理。安装本地声音模型.cmd 下载组件与模型；含声音模型的启动入口设置 LOCAL_TTS_URL。下载时只取公开模型文件，用户样音不上传至第三方。
本机模型安装、CPU加载、真实音频生成和平台API完整链路已通过；详见 verification.md。用户本人样音相似度与发音准确性仍需实际试听。
参考音频模型可在匹配样音中复用声音，但0.6B Base没有独立情绪指令能力；不能把UI选择情绪说成模型已应用情绪。后续另选支持真实情绪控制的模型，分别评测。

## 样音建议与限制
10–30秒、清晰单人、对应文字准确，模型输入要求3–60秒。支持WAV/MP3/OGG/WebM/M4A，10MB上限。保存接口只校验音频容器签名；真实解码和时长检查由模型服务执行。建议使用本人或许可明确的声音，配音用途授权与素材来源另行管理。
CPU服务每次最多500字，长稿分段仍待实现。真正的模型生成延迟、中文发音、声音相似度、情绪强度、取消和录音质量都需要实测。

官方参考：[Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS)，[浏览器语音](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis)。
