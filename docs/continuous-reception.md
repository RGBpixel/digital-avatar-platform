# 连续交谈与多人轮流建档
连续交谈默认开启；开始陌生人接待后，问话朗读结束才开启麦克风，每次转写后先释放麦克风再回答，回答结束700毫秒后继续听。结束按钮停止录音、取消未完成的识别且不发送；打断、切换对象/场所、隐藏页面停止监听。空白识别或错误暂停，避免无限重试。
客人1/2/3是人工选定的临时独立草稿与聊天上下文，支持轮流接待，不代表人脸或声纹识别。切换不会保存未确认资料；每个后端建档会话10分钟到期，刷新页面临时草稿丢失。确认后才保存人员档案。共享麦克风同时只能一人讲话。
已实现：连续语音调度、问答与确认建档、独立客人会话切换。待实测：用户实际连续讲话、扬声器回声环境。待实现：自动认人、多人同时说话分离、自然语言自由填写提取。当前建档仍为规则步骤。

验证：46项自动测试通过，包括朗读后再监听的调度、停止后不重启和两人交错建档隔离。当前浏览器实测已连续推进到兴趣与今日意向步骤；识别存在错字，完整语音保存流程仍需用户验收。测试入口使用临时模型配置及人员数据库。
