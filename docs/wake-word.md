# 唤醒词与收音设置
设置 → 语音输入识别：自定义唤醒词（2–30字）、回答后无讲话的空闲结束时间（2–60秒，默认5秒）、开启/关闭唤醒监听。展示页每句话的收音停顿可选0.4、0.6、1秒。两种时间分别控制本句话提交和整轮结束。
首次开启需麦克风权限与用户点击；后续无需点击开始按钮。仅直接语音+项目本地识别支持。等待唤醒时先在本机转写，用忽略标点的句首匹配；未匹配不送聊天模型，唤醒词后有问题时，去掉唤醒词并直接交给现有对话流程。回答期间不录音。无人继续说话则返回待唤醒，持续检测直至用户关闭、切换模式/场所或离开页面。
配置保存在本浏览器，刷新后不自动开启麦克风。可更改后重新开启。后台ASR不保存音频，未唤醒识别文本不展示。
实现为录音转写式唤醒，依赖现有Whisper本机服务，需短暂停顿，尚非专用低功耗关键词模型；未接入说话人身份识别。模拟测试覆盖未匹配不发送、匹配自动对话、空闲返回等待和关闭后不重启。真实麦克风唤醒准确率与页面听感待用户验收。

2026-10-14：默认20条可编辑的唤醒回应，每行一句，浏览器自动保存；最多40条、每条80字，空白或无有效条目时恢复默认库。随机选择并避免连续两次重复（只有一条时例外）。只说唤醒词时直接使用当前角色音色播放短句，不调用云端对话模型、不写入聊天历史和人员档案。含问题则直接回答问题。播完回到连续收音；取消/切换时停止播放，不复活麦克风。实际真人听感待验收。

2026-10-14：新增可编辑结束语，默认“谢谢”“再见”“谢谢再见”，忽略标点的整句匹配，避免“谢谢，请介绍餐厅”被提前结束。收到结束语不调用对话模型；已开启唤醒则回到待唤醒，否则停止连续交谈。修正收音停顿与整轮超时混淆：每句默认600ms，旧5/10秒收音设置加载时恢复600ms；5/10秒仅用于回答后无人说话的整轮超时。基于音量的停顿检测仍受背景噪声影响，实际麦克风体验待验收。

静默反馈修复：唤醒按钮加入用户手势音频解锁；录音停止时清除旧的最长录音定时器，旧计时器不会结束新录音。持续高于音量阈值时，待唤醒最多3.5秒、交谈最多8秒提交，防止背景噪声拖住上传；较长讲话可能被此兜底提前分段。未匹配显示状态，不展示陌生人的未唤醒转写。识别服务和TTS服务实测ready；17项输入测试通过，其中新增持续声音自动上传验证。真实麦克风及浏览器播放仍待用户确认，不能把上述缺陷认定为已确认的唯一故障原因。

收音上下文修复：首次用户点击时创建并解锁AudioContext，各轮自动收音复用同一个上下文，只释放当前音轨/分析节点，离开页面才关闭上下文。分析链连接零音量输出，以持续取得麦克风采样，不播放麦克风声音。若上下文被浏览器暂停，明确显示需要点击重新开启，不等待悬挂的resume。新增模拟回归验证首次解锁与多轮复用；浏览器控制超时，用户实际页面状态尚未获得，故仍不能宣称真人唤醒已修好。

未匹配问题与界面优化：唤醒按钮、唤醒状态、语音输入状态、本轮转写全部移到角色展示页统一查看；设置页保留参数编辑。待唤醒请求将当前唤醒短语作为hotwords提供给本机Whisper（30字限长），普通交谈不传此提示；不把未匹配结果强制视为唤醒。待唤醒断句固定1秒，普通交谈仍使用所选停顿。识别结果显示“本轮唤醒识别”，支持宝贝/寶貝的常见字形，尚非完整繁简转换。22项测试通过，服务重启生效，未更换模型权重；真实音频识别准确率尚未确认。
