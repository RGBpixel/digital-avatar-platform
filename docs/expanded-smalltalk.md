# 扩展自然攀谈
单人已关联时，任务口讯仍最高优先，无任务才选一个话题：普通问候、近况关心、已确认兴趣、本人过往话题、可见物品/衣着。每人记录近期6条话术，避免相邻同类；不再由衣服观察覆盖全部其他话题。每次最多一个问题，后续由现有多轮对话接住回应。

兴趣只使用本人确认且已允许个性化的资料。过往话题只从当前对象最近8轮中的本人提问识别旅行、游戏、影视、运动、阅读主题，不将模型旧回答当作事实，不替人断言旅行已成行。近况使用“今天感觉怎么样”式询问，不从脸推断气色健康疲惫。

视觉2B新增书、鲜花、杯子、雨伞、背包、手提袋、行李箱、球拍、篮球、足球有限标签。不猜杯中饮品、物品内容、目的；看不清不强行使用。单帧画面和观察仅留本机，不加入云模型提示，不写入人员档案。多人继续只公开问候，不使用这些私人记忆话题。

物品判断准确率还需真实摄像头现场测试；关键词选题与规则轮换已实现，不是人类情绪或健康判断模型。

手机补充：加入手机/智能手机/移动电话标签归一化；不猜品牌、不读屏幕和聊天内容。视觉测试区显示物品标签，识别到物品不保证当轮一定选择该话题，话题仍轮换。

开放物品扩展：不再仅接收固定物品名单，可接收最多3个简短随身物品描述。品牌只尝试清楚的衣服文字标识，回执同时提供品牌名与可见文字，不匹配或缺失则丢弃；这是模型报告的一致性检查，并非独立OCR核验，仍可能看错。输出使用“好像有某字样”而非断定品牌、价格或真假。模糊图形Logo品牌识别尚未作为可靠功能。

实时看图修复：聊天明确询问“我手里拿的是什么”“这件衣服什么牌子”时走本机观察/OCR，不送不带图的云聊天。物品专用模式允许物品特写；普通画面最大640宽，OCR中央65%区域最高960宽。新增读衣服文字按钮，使用独立CPU RapidOCR 1.4.4（隔离目录services/vision/runtime，不修改TTS环境），首次启动OCR进程后复用。读到NIKE测试图置信度0.988、OCR计算约447毫秒；不代表真人衣服效果，也不验证真假。画面只在内存处理、不过云、不保存。仍需真实镜头清晰对准物品/衣服标识验证。
