# 兴趣资讯池

公司/社会两类保持不变，新增综合、幽默趣闻、体育、游戏、旅游、娱乐、科技、文化主题，以及资讯/新闻和趣味段子两种内容类型。设置→公共资讯与天气可筛选、人工补充和停用；原有资讯自动按关键词归类，不修改人员原档案。

按本人同意个性化、已确认的兴趣文字进行本地规则匹配和排序，不依据脸、声音猜测兴趣。聊天模型上下文与主动开场均优先对应主题；没有匹配项则选择其他有效轻松话题。本人明确表示换话题时当前意愿优先。保持个人留言优先、每人3小时开场冷却、单条7天不重复、场所及内部可见范围。兴趣分类目前是关键词规则，不是训练后的推荐模型。

自动更新中新网官方综合、体育、文娱、生活、创意RSS，最近72小时、带来源与日期。新鲜游戏内容依赖订阅是否报道，可人工录入；Steam专用订阅本机实测超时，尚未启用。按需搜索新增游戏、旅游、轻松趣闻固定公共关键词，不发送个人姓名、兴趣档案或原话。网络不可用时不伪造新闻。幽默段子明确为虚构，不包装为真实事件；灾难伤亡新闻不作为轻松开场。

来源订阅目录：https://www.chinanews.com.cn/rss/ 。原有独立幽默模型的可替换接口规划保留，本次没有训练或替代该模型。

自动刷新周期为每小时，启动时立即刷新；关闭程序期间不运行。各来源完整抓取成功后按新批次替换，已不在本批中的自动新闻删除，同URL保留相同ID，不重置个人已聊历史。空/无效响应不清空旧内容，部分来源失败只补充成功结果，完整失败保留有效缓存；过期内容仍清理。人工录入的资讯、公司通知、段子不随自动新闻换批删除。
