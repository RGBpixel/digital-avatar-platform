# 主动接待与交谈式长期记忆

## 已实现流程
设置页启用“检测到单人到来时主动问候并开始引导建档”，选择新档案保留期限30/90/365天。原生FaceDetector可用时，连续两次检测到单人触发；本轮有人期间不会反复问候，离开后重新等待，问候间隔至少30秒。多人时提示人工确定对象，不自动混合资料。模拟来人也可验证；检测事件只有人数，没有可靠永久身份。

展示页可直接点击“开始陌生人接待”。依次回复称呼、兴趣偏好和今天想做的事情；可跳过可选项或取消。机器人给出草稿与保留期限，请本人回复“确认保存”或“同意保存并用于个性化聊天”才登记；“好的”等含糊回答不保存。建档以新内部ID创建，不能因为同名而修改别人。无同意时仍可普通咨询。

在设置页选择已登记人员并模拟确认当前交谈对象，回展示页点击“通过交谈修改当前真人档案”。说“修改称呼”或“修改兴趣”，按提示填写新值；说“记住：昨天参观了博物馆”可添加事件摘要。核对后“确认保存”才写入；取消不保存。草稿保存前若原档案已被其他操作更新，会拒绝覆盖并要求重新查看。修改不自动延长原期限。

文字或已识别语音文字均可作为回答，语音当前仍须确认文字后点击发送。启用自动朗读时可用所选声音读出问候和询问；没有自动开启麦克风或摄像头。

## 数据和接口
GuidedReception以10分钟内存会话保存草稿；POST/api/guided-start与POST/api/guided-chat均按场所隔离。既有人员编辑需当前PersonalConversation短时模拟关联，不能仅提交personId；每轮重新检查授权和档案是否有效。不是生产可信身份认证，仍只供本机控制台。确认完成后Person资料与事件摘要存入本机SQLite，跨重启保留。
MemoryItem=text、source=user-confirmed、recordedAt、expiresAt；记录时间是保存时间，不推测事件发生时间。每人最多20个事件，每条300字，查询最多取最近5个确认事件；保留旧摘要和独立资料，不保存整段聊天。普通偏好更新保留其他字段。没有永久无限期保存，默认30天，到期访问时清理；一年档案需在确认提示中明确期限。既有登记仍遵守原30天同意。
规则引导独立于大模型，建档流程本轮不调用云端，模型不能直接修改数据库；普通聊天仍可调用所选本地或云端模型。经授权的关联聊天可读取近期事件，云端仍需独立传送同意。幽默模型独立接口与权限约束保留。

## 待完成
真实摄像头仍返回无设备，实际人脸检测/身份确认与多人追踪未验收；浏览器不支持FaceDetector时无法自动触发。自由语言识别修改意图、实时双向语音、模型记忆候选抽取/去重/相关检索、真人头像登记和生产账户权限待实现。当前为规则引导的交谈建档，不能称为已完成自主学习或真人识别。

## 验证
30组自动测试通过。新增草稿不提前保存、含糊确认不保存、拒绝仍可接待、同名不合并、保留期限、修改与事件需二次确认、撤回授权/到期/跨场所拒绝、并发修改不覆盖；前端语法检查通过。真实浏览器新流程验收需重启最新后台后进行。

已确认交谈对象且开启个人化聊天后，成功完成的模型问答按场所与 Person ID 存入 data/chat-history.sqlite，重启保留。下次确认同一人时，向对话模型提供最近8轮历史（每轮回答最多1000字用于上下文），原始文本保留至人员档案到期。匿名对话、失败及未完成回答不归档；不保存音频。撤回个性化授权或删除/到期时清除记录（访问时清理），不保证SQLite历史字节物理擦除。沿用现有云端资料单独授权。历史对话不是已核实档案，不自动改写公司职位或授予权限。完整历史浏览、全文检索与更早记录自动摘要尚待实现。
