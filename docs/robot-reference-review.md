# 机器人参考视频：观察与验收目标

来源：用户上传 2026-10-12 011739.mp4；时长约 192.3 秒。对应此前分享的头条参考。
分析范围：按 6 秒间隔抽取画面，检查可见字幕；未完成音轨转写或连续逐帧分析。以下不是完整对话记录。

## 可见内容
家庭内有机器人、宠物和上门人员；字幕呈现陌生来访、询问身份、对身份真实性的疑问以及之后的任务交流。视频还有剪辑说明字幕，不能把所有字幕都当成机器人实际发言。
片段可作为现场接待、身份澄清和情境对话的交互参考，无法独立证明长期记忆、真实自主运行或未剪辑的响应延迟。不能确认背后的模型和技术。

## 项目验收目标（依据用户需求制定，非视频已证明的能力）
- 在陌生人自述身份后，用简短问题确认目的与接待对象；自述不自动产生权限。
- 跨多轮记住当前任务、称呼及已经回答的问题，避免重复盘问；听到纠正后更新当前上下文。
- 语音不清、识别不确定、画面看不见时明确说明，追问而非编造。
- 通过许可登记的档案和检索支持跨次到访记忆；拒绝登记仍可使用临时会话。
- 多人交谈时区分发言对象，未确认前不把甲的信息写入乙的档案。
- 在实际环境测量用户说完到首段可听声音的延迟，记录中位数和 P95；测量打断到停止播放的时间。不从剪辑视频推定性能。
- 对话风格按场景切换：企业接待礼貌准确，餐厅可轻松，小剧场可启用更强幽默；幽默不影响任务执行。
- 业务动作有独立权限、工具回执及失败处理，不把生成回答视为通知或开门已经成功。

## 所需评测案例
初次来访→昵称登记→新会话再次来访；偏好改变；同名人员；身份误匹配；未知信息；两人交替说话；任务中途改口；打断；网络延迟；通知失败。
分别评价记忆准确性、上下文理解、接话质量、语音时延和业务成功率。长期记忆工程与幽默训练分开开发、联合验收。
