# 人员业务配置与模型操作接口

`config/person-actions.json` 独立配置昵称、兴趣偏好和本人提醒操作的开关、名称与长度限制。修改后重启后台加载。此文件只定义规则，不保存真人资料或密钥。

人员昵称、兴趣仍以原人员卡片数据库为准，个人提醒仍保存到原留言数据库，按场所和人员ID隔离；没有复制或迁移已有数据。后台 GET /api/person-actions 返回业务规则，POST /api/person-actions 接受 personalSession、action、value。调用方不能指定其他人员或任意文件路径。

已关联本人、允许当前云端调用时，非固定表达可由当前对话模型以工具调用方式选择操作。规划请求只携带本句话和工具说明，不附带人员卡片及历史。昵称和兴趣明确委托后直接保存；提醒先复述核对再进入原保存流程。不接受管理员、门禁、程序源码操作。服务商不支持工具或规划超时时仍保留原对话及确定性解析。

已实现配置接口和模型工具路径，自动测试覆盖受控写入与隔离；实际自然语音工具选用效果还需现场验收。当前会话关联沿用本机原型机制，不作可信身份鉴权。
