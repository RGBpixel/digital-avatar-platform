# 本轮说话者声纹锁定
实现：角色展示页默认勾选“唤醒后仅接受当前说话者”。唤醒词转写匹配后，使用本轮唤醒录音建立声纹参考；后续整段音频先匹配声纹，未匹配不转写也不发送到云端。模型3dspeaker_speech_campplus_sv_zh-cn_16k-common.onnx，官方发布来源和文件SHA在models/speaker-campplus/source.json，CPU两线程运行。
API：/api/speaker-lock、/api/speaker-release；/api/asr带X-Speaker-Session。随机会话令牌按场所隔离；声纹向量仅存在本机ASR服务内存，无声纹/录音档案写盘。结束语、空闲结束、关闭、切换模式/场所释放；刷新/异常中断残留最长10分钟过期，最多16个会话。不是员工身份认证，不接门禁。
有效讲话至少约0.5秒；仅单句唤醒建立的参考可靠性有限，锁定失败明确提示重说。余弦阈值0.65是原型默认值，未做目标人群/麦克风标定。非常短的“嗯”等可能被拒绝。录音内多个人同时讲话会污染特征，当前没有声音分离/目标人声增强，不能保证旁人声音被完全去除，也不能防录音重放。只拒绝整段未匹配的音频。
验证：Windows合成唤醒音频锁定0.078秒；同文件匹配1.0，另一公开中文说话音频-0.048被拒绝，跨场所和释放后拒绝。见data/speaker-verification.json。同文件重复不是同一真人说不同句子的验证；真实双人、多轮与噪声效果待用户验收。Python规则测试包含接受/拒绝/样本不足/跨场所/过期/释放；Node回归覆盖前端锁定/空闲后重新锁定、ASR状态转发。
官方接口来源：https://k2-fsa.github.io/sherpa/onnx/c-api/html/speaker_embedding.html

逐段加固：超过2秒的录音除整段评分外，按2秒窗、1秒步长检测声纹，任一有足够有效语音的窗口不匹配则拒绝整段。保留0.65阈值以避免未经标定的盲目提阈值。前端锁定令牌丢失时回到待唤醒并停止发送。Python2项、Node24项通过，真实模型测试同声重复通过、先同声后异声被拒绝。此测试不是不同句子/现场混音准确率验证。逐段验证增加CPU计算，未测真人端到端延迟。短唤醒参考仍可能误拒绝/误接受，建议在安静环境用唤醒词加一整句话建立较长参考。

第二轮误拒绝修复：实测同一Windows合成说话者说不同句子，原规则整句0.707通过但短窗口0.622触发拒绝。整句仍需0.65，短片段单独采用0.50容差，避免每个短音节都强制达到整句阈值；低置信度结果标为uncertain并提示清晰重说/重新唤醒，不擅自绕过验证。前端拒绝时更新本轮提示和评分，避免只残留唤醒文字。实际API新测试两个不同句子通过、另一说话者拒绝；Python3项及Node24项测试通过。见data/speaker-second-turn-verification.json；这是合成声音测试，现场同一真人不同句子/手机视频效果仍待验收。阈值是原型值，不表示已在人群和麦克风上标定。

继续交谈修复：实际页面显示整句约0.65、最差分段0.029导致拒绝。现只检查完整2秒窗口且至少1.2秒能量有效语音；忽略不足窗口的尾音和有效语音不足片段，仍保留整句门槛。新增“重新采集我的声纹”主动入口，连续说3–5秒（至少30个80ms有效帧），操作者明确发起后才更新参考，不自动把被拒绝音频学习为本人。采样不发送对话模型，锁定后播放提示并自动进入连续交谈。自动化覆盖采样后第二/三轮自动重开麦并携带令牌；真实现场待验收。

收音可观察性与恢复：角色展示页显示当前第几段、收音秒数和是否检测到讲话，另保留上一段上传/拒绝/失败结果，避免循环收音覆盖故障信息。单次识别请求失败后1.5秒重试，连续最多3次，手动停止会取消重试；健康检查不可用仍明确暂停。新增校准后第二/第三轮带令牌与临时上传故障恢复回归。真实用户声纹尚需使用主动3–5秒采样入口验证，不将测试通过等同现场成功。

稳定交谈默认模式：现场UI曾显示整句0.9089但分段最低0.0801仍被拒绝，说明逐段一票否决误伤明显。现默认conversation仅以整句0.65判断，不再计算/否决短窗；严格分段仅在用户主动勾选时启用，按X-Speaker-Mode传递，两种模式都保留场所/令牌/过期校验。默认不能承诺拦截同一句混入的视频声音；严格模式仍有误拒风险。4项Python规则与26项Node回归通过；实际API不同合成句子通过、公开另一声音拒绝。用户真人现场仍待验收。

CAM++ Advanced试用切换：用户明确要求替换后，将已对比文件复制到models/speaker-campplus-advanced，核对其SHA与实验清单一致。data/speaker-model.json选择campplus-advanced，重启后继续读取；原CAM++保留。选择器只接受固定枚举，未知/缺失模型报错而非默默回退。服务健康与前端显示当前模型；阈值、收音、临时声纹保留策略不变。模型改变后需要重新采样，不能跨模型复用向量。实际接口验证Advanced就绪、同一合成声音不同句子接受、公开另一声音拒绝，见data/advanced-switch-verification.json；现场真人效果未确认。回退可将model设回campplus并重启识别服务。

误拒绝与转写区分：现场声纹0.57被拦截时ASR尚未执行，已将“没听清”更正为“声音尚未确认”，界面明确标记未转写。增加用户主动确认按钮，仅uncertain录音会在当前网页内存暂存最多60秒；用户明确点击后调用speaker-update补充本轮参考，再重新转写原录音并按普通对话发送。参考最多3条，保留初始参考；不改变阈值、不自动学习拒绝音频、不延长原10分钟期限、不写磁盘或人员档案。结束/切换/页面离开释放音频与向量。真实ASR理解能力与声纹误拒应分别验收。

低分误拒绝恢复修复：现场出现0.2393拒绝；旧按钮只对uncertain显示，other-speaker没有纠正入口。现所有可恢复的声纹拒绝（相近、低分、过短）均允许用户主动确认，并将用户确认的录音替换当前参考，而非保留可能错误的初始参考。门槛不变、模型不变、不会自动更新，仍只在内存驻留至原期限；旁人/视频声音不要确认。原始旧参考在确认后不再接受。本轮尚不能确认根本解决了现场声纹稳定性，只修复了误拒绝无法恢复的问题。

确认等待期：等待手动确认时，5秒无讲话不再提前删除待重试录音；最多60秒后自动清除，手动关闭监听仍立即清除。回归测试覆盖低分0.2393拒绝、空闲6秒按钮仍可用、确认后重试。真实API替换后合成地址问题正确转写、另一声音拒绝；真人稳定性未确认。

确认按钮可发现性：不再按是否存在拒绝录音隐藏按钮，始终在当前声纹模型下方显示。无录音时禁用并明确提示开启监听；有待处理录音时可点击；60秒过期显示清除原因，停止监听显示本轮已结束。保持原有手动确认及本机临时数据策略不变。
