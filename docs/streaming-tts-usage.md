# faster-Qwen3流式声音已接入

2026-10-13，用户明确选择后，正式平台启用faster-qwen3-tts0.5.4，使用原Qwen3-TTS0.6B-Base权重和原已授权样音。原qwen_server.py与环境保留，主启动入口依据data/fast-tts.enabled选择引擎，自动预热。没有新增用户必须运行的入口。

平台实现同源POST /api/tts-stream，后台先校验场所与样音归属，再代理本机9880。服务逐块输出PCM16，浏览器WebAudio持续排队播放；在整个网络流和播放都结束后才继续监听麦克风。停止会取消网络并停止已排队音频，关闭后台请求，错误不伪造完成。300字以上的长稿继续分段。系统声音选项保留，现有WAV /api/tts兼容保留。

样音特征最多4份、按5分钟有效期复用，仅存在内存；删除样音清除模型缓存，不额外保存原始录音。SDK图预热约十余秒，启动时完成，不是每次对话都执行。此Base模型未保证独立情绪控制。

验证：52项自动测试通过。正式平台接口同句首块0.710秒、0.277秒，整段2.168秒、1.180秒，10块与6块；中途取消成功，声音服务继续ready。见data/streaming-verification.json。测试包含随机生成，不能据此承诺所有句子或完整ASR+LLM对话均为0.3秒。浏览器自动控制连接超时，实际播放连贯性与听感待用户刷新后体验。

当前声音选择保存在浏览器中，需要刷新当前页面加载新脚本；仍选择已保存样音。点击开始语音或试听时解锁浏览器音频权限。

恢复旧引擎时去掉data/fast-tts.enabled标记并重启声音和项目服务；这不是模型或样音删除。依赖来自独立experiments/tts-streaming/.venv-fast与fastdeps，只读复用已有CUDA运行库，原Qwen依赖未改动。
