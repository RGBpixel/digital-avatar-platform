# 任务口讯优先规则
已确认的本人出现后先读取本机待告知栏，有未读任务时优先转达，不播放天气、新闻或闲聊开场。新一次到访重新提醒未读事项；播报过不等于收到，只有本人说知道了/收到或点击已读才标记收到。原始内容、留言人、创建时间持久化在 person-messages.sqlite，重启后仍保留到人员档案有效期。支持“提醒我…”和“下次见到我的时候提醒我…”，先核对收件人与正文，确认保存成功才承诺记下。普通模型聊天不得声称已经安排提醒。
本次检查本机 person-messages.sqlite 没有记录，不能恢复或猜测未实际保存的旧任务；请重新交代并完成确认。已有人员、照片与聊天存档未删除。
