# 本机视觉理解2B试用

模型：Qwen3.5-2B，Unsloth GGUF Q4_K_M及F16视觉编码文件；原始模型来自Qwen，量化转换来自Unsloth。运行程序为llama.cpp b11707 Windows CUDA12.4。独立部署，不改变TTS或ASR Python环境。仅监听127.0.0.1:9884，API只能把单张JPEG送往该本机地址。画面不写磁盘，不传云端；当前衣着观察也不加入豆包提示词。

启动项目.cmd自动尝试启动视觉服务。摄像头区新增“本机视觉理解·2B试用”，勾选允许本机分析后点击观察当前画面。按本次试用授权默认开启，可随时取消；开关保存于当前浏览器，已允许摄像头处理才可分析；未开启则原有人脸识别、聊天照常。自动见面攀谈只有任务已处理且单人稳定识别后才尝试，失败使用普通问候。

仅试验衣服颜色及种类，屏蔽气色、健康、情绪、身份推断。颜色/种类是小模型预测，不是真实测量，可能看错；脸部特写或遮挡应回到普通问候。当前不是任意图片问答或持续视频理解。CPU/显存和TTS同时运行表现以实测记录为准，不承诺固定延时。

来源：https://huggingface.co/Qwen/Qwen3.5-2B 、https://huggingface.co/unsloth/Qwen3.5-2B-GGUF 、https://github.com/ggml-org/llama.cpp/releases/tag/b11707 。

## 2026-10-17本机实测
采用GPU运行语言部分、CPU运行视觉编码、上下文1024和Flash Attention。原全GPU方案首图约30.8秒，已弃用。调整后经/api/vision-observe分析本机构造蓝色T恤图，两次约968毫秒和218毫秒；第二次含同图缓存收益，不代表任意图片延迟。识别结果蓝色T恤；显存总占用6433MiB/8151MiB，包含其他已有服务。TTS健康检查仍可用，但尚未验证真人摄像头准确率与持续语音/视觉同时推理压力。133项测试通过。
自动攀谈最多等视觉2.5秒，超时仍用普通问候。按本次试用默认启用，页面可关闭自动视觉或整体视觉；不会影响任务优先转达。
