# 本机中文识别修复（2026-10-13）

用户实测浏览器识别未收到讲话，前次只验证启动而没有验证真人转写，不能算通过。本轮默认切换为项目本机faster-whisper-base录音转写；原浏览器识别作为备用，在设置 → 语音输入识别中选择。普通启动项目.cmd自动启动本机ASR，不需要新增CMD入口。

展示页：选择直接语音互动 → 点击开始 → 等待“本机识别正在收音” → 看音量条并说一句 → 停顿约1秒或点击结束 → 本机转写 → 自动发送。最多30秒；12秒未检测到发声会结束。没有识别结果不发。麦克风菜单可选择明确的Realtek麦克风阵列，避免Pico/VIVE等虚拟设备；原系统默认在实测中也指向Realtek。

录音临时保存在浏览器内存，结束后仅发送到本机Node API，再到127.0.0.1:9882；不上传云端、不保存原始录音文件。浏览器服务和在线识别没有被静默启用。对话模型仍按原配置，ASR本机不意味着LLM本机。

服务为独立Python CPU int8识别，faster-whisper1.2.1、CTranslate2 4.8.2，保留已有PyAV19与TTS依赖。下载Systran官方模型并记录revision，LFS文件校验SHA256。已修复faster-whisper解码API与PyAV19不兼容问题，使用本机PyAV重采样；运行离线，不自动下载其他模型。

证据：本机服务health.ready=true；使用已有合成中文测试音频（原稿“你好，欢迎参观。”）通过平台API实际返回“你好,歡迎成官”，2.16秒音频，约0.422秒识别，RMS0.0583。这证明音频转写链路真实可用，但有词误识别；不宣称准确率已达标。真人讲话与扬声器闭环仍需重试。浏览器实测录音已进入本机接口，环境声录音未识别到讲话；音量条测到约9%，没有保存录音。

43组自动测试通过，含音频上传、单次自动发送、取消后晚到音轨释放、ASR错误与空结果不伪造；真实音频验证与测试桩结果分别记录。本轮曾修复启动脚本UTF-8 BOM编码、缺失模型词表、PyAV解码兼容和测试时序。模型升级、识别质量/低声环境评估、长期VAD校准后续依据真人测试进行。

资料：[faster-whisper](https://github.com/SYSTRAN/faster-whisper)、[模型来源](https://huggingface.co/Systran/faster-whisper-base)。

## 2026-10-13 识别与归属理解升级
优先加载官方 Systran/faster-whisper-small 多语言模型，CPU int8，beam_size=5，保留base回退；以source.json完成标记决定启用，下载未完成不切换。实际准确性需用户发音验收。
建档归属支持自然表达与否定表达，疑似内步/内布等误识先询问核对；不确定、外包或混合关系继续澄清，不推定内部权限。

真实测试：small服务ready=true；2.16秒的既有合成测试音频“你好，欢迎参观”识别为“你好,歡迎參觀!”，耗时1.078秒。之前base同一文件结果含“歡迎成官”错字。此结果仅为该音频样本，不代表真人短词准确率已验收。
