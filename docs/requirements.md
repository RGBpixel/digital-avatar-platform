# 已确认需求

## 产品目标
兼容网页、手机、UE 虚拟小剧场，预留未来 Steam 桌面版本。支持实时语音互动及文本口播视频制作。

## 角色
2D 卡通人物和动物、3D 人物和动物、机器人、MetaHuman。外形与人设可分别替换；可保留或独立配置记忆和声音。
角色声明支持的嘴型、表情、手势与移动能力，不支持的指令采用替代表现。
服装更换、材质及布料动画分阶段实现，各平台采用适当精度。

## 实时互动
麦克风输入、流式回答、播放同步、基础表情、倾听状态及用户打断。音频与动画共享播放时钟，取消回答时取消关联动画。

## 视频制作
提供文本或资料；严格朗读与改写口播两种模式由用户选择。森林、办公室、舞台背景及上传背景；支持横竖屏、字幕、预览、分段重做、视频导出。
直播推流与弹幕互动是后续扩展，不等同于视频导出。

## 幽默能力工作线
学习清一色及其他待核实创作者的互动机制：主持人先发问、接话、反转、回扣、控场、汇总观众故事。用户追求强幽默和有主导感的主持风格。
素材先整理、溯源、去重、提取机制，再制作新情境样本和评测；训练方式与基础模型待数据和评测确认，不承诺仅收集视频即可获得能力。
该工作线不阻塞数字人原型。先使用现成对话服务，后替换幽默模型。

## 当前限制
用户本机有 Codex 和 VS Code，硬件、依赖和 UE 安装状态未核实。此项目包未连接本机，也未配置真实语音或模型服务。

## 企业前台与餐厅接待（2026-10-12 新增）
平台扩展为现场数字接待系统，部署于企业门厅、餐厅门口及其他服务场所。详见 service-reception.md。
支持摄像头接入、人员追踪与自愿登记、可管理的长期记忆、员工与访客权限、飞书/钉钉通知、受控门禁及餐厅熟客偏好。
摄像头品牌不是协议保证；海康威视等设备必须核实型号、固件及实际接口。追踪、人脸匹配、语音采集分开适配。

待实现：真实语音、真实大模型与幽默模型、音素同步、真实角色资源、视频导出、3D/MetaHuman/UE、摄像头/身份确认、账户及持久化长期记忆、真实员工目录与确认、飞书/钉钉和门禁设备。保留全部原定产品目标。

## 客户可配置的数字服务岗位（已确认）
平台不是仅供企业/餐厅使用的固定前台。客户可配置场所、数字机器人岗位、工作环境、工作职责、知识范围、接待与讲解流程、语气、问候语、人工接管说明；形象、声音、人设、业务岗位分离。支持企业、餐厅、展厅、景区、博物馆、家庭助理、培训机构、美容院及自定义行业模板。
一个行业模板可实例化为多个独立场所，企业/家庭数据默认隔离；场所 ID 与行业类型分离，不以行业名划分所有客户的共用档案。岗位说明是行为配置，设备操作须独立业务授权。家庭看护助理作为数字问询、提醒、联络角色规划，实体家务/照护能力不能由岗位名称推定。
当前已提供本机场所配置原型与 JSON 保存、模板、新建独立场所和模拟问候生效。客户账户、租户权限、知识库、可执行工作流、设备/业务配置与真实模型行为待实现。

## 全身展示与页面布局（已确认）
角色应有完整头部、躯干、双臂双手、双腿双脚；提供可选人物、动物和机器人形象。默认独立“角色展示”标签页，集中显示全身角色和互动；“设置”标签页集中形象/背景、岗位/场所及设备配置。切换标签不丢失当前表单。当前八种形象是全身二维程序示意资产，正式资源与骨骼/动作适配后续实现。

## 可配置画面与取景（已确认）
客户可选横屏、竖屏、方形、圆形和自定义宽高；显示范围独立选择全身、半身或仅头部。角色保持等比，圆形屏通过可见区域遮罩处理，可仅显示头部。当前网页逻辑尺寸支持 240–7680 整数像素；圆形要求等宽高。预览自适应缩小，不修改操作系统/设备实际分辨率。视频输出尺寸、UE 取景及设备屏幕适配后续实现。

## 讲解声音与状态（已确认）
角色声音可选预设声音库，或通过本人/已授权样音录制、上传生成后续讲解声音。声音身份与性格、情绪、强度分开配置。性格初步支持活泼、沉稳、温柔亲切、故事讲述；情绪支持自然、愉快、情感饱满、忧伤。角色回复可选择自动朗读；同一场所和角色沿用保存声音。
当前本机声音库可走浏览器TTS控制链，只有基础语速/音高近似情绪；上传/录制/样音库管理已实现。真正参考音频克隆需要已安装并成功启动的模型，不能把原始样音回放当成新讲解声音。模型的声音克隆与情绪指令能力分别验收。


## 真人档案与个人上下文（2026-10-12）
真人 Person 与数字人 Avatar 独立。按独立场所 ID 隔离，以永久 Person ID 关联员工、顾客、访客的逻辑目录；同名不同人使用不同 ID。类别是档案分类，不授予员工身份或门禁权限。
已实现本机 SQLite（data/people.sqlite）保存称呼、类别、本人同意、偏好、标签、经确认的交流摘要及来源/时间，重启保留；可手工纠正、切换分类与撤回删除，默认30天到期访问时清理。摘要最多2000字，标签最多20个。来访、通知与审计仍为内存模拟。数据库文件不提交。
设置 → 真人档案与模拟接待：登记分类后，在员工库/顾客库/访客库筛选，选择人员查看编辑偏好、标签和摘要。仅本机后台操作人员界面；没有账户权限，不向访客自动显示资料。未经确认不保存推测性标签或全量聊天。
待实现：可信身份核实、实际摄像头和自愿人脸登记；会话中的短期上下文；身份确认后受权限控制的长期记忆检索/自动摘要确认；租户与账户授权、数据库加密、备份及物理删除策略。当前删除为逻辑记录删除，不保证SQLite空闲页中的历史字节已经不可恢复；生产接入前需完成数据治理。

## 麦克风输入与真实摄像头预览
展示页新增开始/结束语音输入：默认要求浏览器本机中文识别能力及语言包；否则明确不可用。可由使用者单独勾选允许浏览器在线识别，音频可能由浏览器提供商处理；不自动下载、不静默改用在线服务。识别文字先填入文字框，人工确认发送，最长60秒，结束/离开页面停止。浏览器支持范围参见 https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition 。
点击开启摄像头，通过getUserMedia真实预览，支持设备选择、关闭、拒绝权限/设备占用报错，等待权限期间取消仍释放晚到流；离开页面或切换场所自动关闭。画面不上传、不录像、不自动登记。原生FaceDetector可用时每秒本地检测一次脸数量（最多5），能力缺失时只预览，明确提示。检测数量不是不同人的永久身份；多人/数量变化需重新确认聊天对象。真实人脸特征匹配、登记头像、人名识别及跨帧可靠追踪仍待实现。
已有摄像头模拟接口保留，用于接待流程测试；对话仍为模拟模型。物理麦克风、摄像头和浏览器识别服务需用户实机验收。

## 2026-10-16 人脸＋档案声纹联合确认（聊天试用）
后台人员档案新增本人声纹登记：人工核对目标卡片、取得本人同意后录制3–15秒，提取当前本机CAM++特征，原始录音不落盘，页面未保存录音最多暂存60秒。每人保留最多3份显式登记参考，保存于data/voice-identity.sqlite，随人员到期/删除清理，可单独删除声纹。与临时旁人过滤声纹区分，不将唤醒录音自动登记到档案。
单人稳定人脸候选有声纹登记时提示回应“你好宝贝，我来了”，本次录音先交本机进行联合核对。后端发放绑定场所与人选、10秒内一次性的核对挑战，并在声纹推理后复查最新人脸候选。声纹分数须达到0.72，且比其他已登记人员至少高0.05（试用参数，未经正式误识率标定）。模型/维度变化要求重新登记，失败不关联、不进入访客问卷，可继续重说或使用现有显式人工确认。联合通过后关联本人已授权聊天与待告知事项，再用当次录音锁定本轮收音以过滤旁人；不自动更新持久声纹。
当前人脸无活体防伪、声纹不能抵御录音重放，不作为门禁、管理员权限或安全身份认证。已实现与自动化测试完成；真实本人录音登记、现场误拒绝率/误接受率和重放防护未验收。
