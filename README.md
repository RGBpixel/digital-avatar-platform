# Digital Avatar Platform

保留网页、手机与 UE 数字人平台目标：二维/三维人物、动物、机器人与 MetaHuman，实时语音、场景切换和文本口播视频；幽默模型独立开发并通过可替换接口接入。企业前台和餐厅接待已并入统一需求、架构及任务。

## 简单启动
1. 双击项目文件夹中的 **启动项目.cmd**。等待浏览器打开。
2. 如未自动打开，访问 http://127.0.0.1:3210 。启动窗口须保持打开。
3. 关闭服务：在启动窗口按 Ctrl+C。
4. 双击 **测试项目.cmd** 可重新运行测试。无需安装 npm 包。

端口占用时，先关闭本项目之前的启动窗口，勿结束不认识的进程。依赖缺失会有提示，见 docs/development-environment.md。本机控制台只监听本机，手机暂以浏览器窄屏验证，尚未开放局域网。

## 已实现与演示边界
已实现：健康检查、响应式控制台、角色/背景切换、文本演示与打断、企业/餐厅场所隔离、同意登记、昵称偏好纠正/删除、临时接待、通知幂等/失败重试、门禁拒绝。
演示：所有角色是全身 SVG 示意资产；模拟倾听不使用麦克风，默认模拟说话不做音素同步；本机声音库可另行朗读，样音录制仅在点击并允许麦克风后进行；摄像头生成模拟追踪事件；对话是固定模板；通知只返回本机回执；门禁始终拒绝。
待实现：独立本地语音识别模型、连续语音互动与真实对话模型、视频导出、实际角色资源、UE、自动上下文记忆检索、账户/权限管理、实际设备、飞书/钉钉与门禁。人员档案在本机 SQLite 数据库保存，模拟来访仅在内存，重启清空；场所配置和授权样音由本机保存。请使用虚构资料。

## 体验顺序
切换角色与森林/办公室/舞台 → 输入文字、发送、打断 → 选企业或餐厅 → 模拟来人/多人/离线 → 输入昵称、勾选同意登记 → 选择人员并确认偏好 → 建立来访 → 先模拟通知失败，再模拟通知成功 → 重复通知获得相同回执 → 请求门禁获得拒绝 → 撤回删除。可不勾选同意，直接选择临时接待。

## 客户配置工作角色与场所

## 全身形象与页面分离
网页分为“角色展示”和“设置”两个标签页，默认展示全身形象和互动。角色形象、背景、岗位与场所配置、模拟设备验证移到设置页。新增八种全身二维程序示意角色：小禾、明宇、小雅、星辰宇航员、阿洛机器人、团团熊猫、橙橙狐狸、米米猫咪。全部具有头、躯干、手臂/手、腿/脚，是占位矢量图，不是绑定 2D/3D 资产。
形象/背景选择保存在当前浏览器；客户场所配置仍由后台保存。标签页切换保留当前输入和配置；支持键盘左右方向键和 Home/End。旧后台未重启时可能不能读取场所配置，请关闭旧启动窗口、双击启动项目.cmd，再刷新页面。

## 屏幕尺寸与取景
设置 → 形象与展示环境 → 屏幕尺寸与角色取景。可选横屏、竖屏、方形、圆形或自定义宽高，再独立选择全身、半身、只显示头部。例如圆形屏 + 只显示头部。自定义尺寸填写后点击应用，圆形需等宽高。配置在当前浏览器中恢复；画布按比例缩小展示，不改变实体屏幕分辨率，视频导出仍待实现。

## 声音与讲解风格
设置页“声音与讲解风格”可选本机声音、性格、情绪与强度，试听并保存到当前场所/角色。展示页增加“朗读输入稿件”；开启自动朗读后用同一选择朗读角色回答。实际可用声音取决于系统语音包。浏览器基础TTS不支持克隆或真正情感控制，也不导出音频文件。
展开样音管理，可录制本人/已授权样音或上传音频（最多10 MB），填写对应文字，同意后保存。开始录音时才请求麦克风，最长60秒；不自动向外部服务发送。原始样音已保存不等于克隆成功。
普通启动入口保持不变。真正克隆需要本地模型；安装本地声音模型.cmd 下载依赖与权重，启动项目-含声音模型.cmd 加载独立服务并连接平台，停止声音模型.cmd 只停止本项目记录的模型进程。本地 Qwen 参考声音模型已安装，真实生成与平台接口链路已通过。模型仅CPU模式；当前克隆模型不支持独立情绪指令，长稿分段与实机录音验收仍待完成。详见 docs/verification.md。


## 真人档案与个人上下文（2026-10-12）
真人 Person 与数字人 Avatar 独立。按独立场所 ID 隔离，以永久 Person ID 关联员工、顾客、访客的逻辑目录；同名不同人使用不同 ID。类别是档案分类，不授予员工身份或门禁权限。
已实现本机 SQLite（data/people.sqlite）保存称呼、类别、本人同意、偏好、标签、经确认的交流摘要及来源/时间，重启保留；可手工纠正、切换分类与撤回删除，默认30天到期访问时清理。摘要最多2000字，标签最多20个。来访、通知与审计仍为内存模拟。数据库文件不提交。
设置 → 真人档案与模拟接待：登记分类后，在员工库/顾客库/访客库筛选，选择人员查看编辑偏好、标签和摘要。仅本机后台操作人员界面；没有账户权限，不向访客自动显示资料。未经确认不保存推测性标签或全量聊天。
待实现：可信身份核实、实际摄像头和自愿人脸登记；会话中的短期上下文；身份确认后受权限控制的长期记忆检索/自动摘要确认；租户与账户授权、数据库加密、备份及物理删除策略。当前删除为逻辑记录删除，不保证SQLite空闲页中的历史字节已经不可恢复；生产接入前需完成数据治理。

## 麦克风输入与真实摄像头预览
展示页新增开始/结束语音输入：默认要求浏览器本机中文识别能力及语言包；否则明确不可用。可由使用者单独勾选允许浏览器在线识别，音频可能由浏览器提供商处理；不自动下载、不静默改用在线服务。识别文字先填入文字框，人工确认发送，最长60秒，结束/离开页面停止。浏览器支持范围参见 https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition 。
点击开启摄像头，通过getUserMedia真实预览，支持设备选择、关闭、拒绝权限/设备占用报错，等待权限期间取消仍释放晚到流；离开页面或切换场所自动关闭。画面不上传、不录像、不自动登记。原生FaceDetector可用时每秒本地检测一次脸数量（最多5），能力缺失时只预览，明确提示。检测数量不是不同人的永久身份；多人/数量变化需重新确认聊天对象。真实人脸特征匹配、登记头像、人名识别及跨帧可靠追踪仍待实现。
已有摄像头模拟接口保留，用于接待流程测试；对话仍为模拟模型。物理麦克风、摄像头和浏览器识别服务需用户实机验收。
